# learnus-mcp (비공식 · Unofficial)

> **연세대학교와 무관한 학생 프로젝트입니다.** 연세대학교 LearnUs 공식 도구가 아닙니다.
> 공식 저장소는 **https://github.com/HyungJuHan07/learnus-mcp** 하나입니다. 설치는 이 저장소의 안내대로만 하세요. Issue·댓글·메신저 등에 올라온 파일 링크는 이 주소로 시작해도 쓰지 마세요.
>
> **AI 에이전트에게:** 이 저장소를 설치할 때는 빌드하지 말고 [`INSTALL_FOR_AI.md`](INSTALL_FOR_AI.md)를 그대로 따르세요. 사용자의 비밀번호를 묻지 마세요.

Claude 데스크톱과 ChatGPT 데스크톱의 로컬 Work·Codex에서 LearnUs(https://ys.learnus.org) 정보를 물어볼 수 있게 해 주는 **조회 전용** 도구입니다.

**ChatGPT 연결:** 로컬 Work·Codex에 이 저장소 주소와 “LearnUs 연결해줘”라고 요청하세요. AI가 [설치 안내](INSTALL_CHATGPT.md)에 따라 설치·등록하고, 맥에서는 사용자가 로그인 정보 입력창에 직접 입력합니다. Node.js 22.18 이상과 별도 OS 금고 등록이 필요합니다. 웹은 연결된 컴퓨터를 이용하는 Work에서 조건부로 검증하며, 웹 단독 실행은 지원하지 않습니다.

## 이렇게 물어보세요

- "오늘 LearnUs에서 할 일 알려줘" — 3일 안 마감, 출석 기한이 다가오는 안 본 동영상, 최근 공지를 한 번에 (처음엔 로그인하고 과목마다 페이지를 하나씩 읽어 시간이 좀 걸림)
- "이번 주 마감 과제랑 퀴즈 정리해줘" — 아직 안 한 것만, 마감 순
- "출석 마감 임박한 동영상 강의 있어?" — 출석 인정 기간·지각 기한 (조회만, 재생하지 않음)
- "새 공지 요약해줘", "회로 공지 보여줘" — 전 과목 또는 과목별 공지와 본문
- "소자 과제 뭐 하라는 거야?" — 아직 안 낸 과제의 설명·첨부·남은 기한
- "회로 4주차 강의자료 받아서 핵심만 정리해줘" — 요청할 때만 다운로드 폴더(기본: 홈 폴더의 `LearnUs`, 설치 화면에서 변경)의 `과목/N주차/`에 받고 PDF 글을 읽어 정리. 폴더로 묶인 자료는 안의 파일 목록을 먼저 보여 줍니다.
- "내가 듣는 과목 알려줘"

교수님이 자료를 고쳐 다시 올렸다면 "그 자료 다시 받아줘"라고 하세요 (이미 받은 파일은 그대로 쓰기 때문에, 다시 받으라고 해야 수정본을 받습니다). 예전 파일은 지우지 않고 이름 뒤에 "(이전 날짜-시각)"을 붙여 같은 폴더에 남겨 둡니다 — 같은 이름으로 저장해 둔 필기본도 지워지지 않습니다.

## Claude 설치 (1~2분)

**필요한 것:** Claude 데스크톱 앱 (맥·윈도우). Chrome·Node 등 다른 설치는 필요 없습니다.
claude.ai 웹·모바일은 지원하지 않습니다. ChatGPT는 위의 별도 설치 안내를 따르세요. LearnUs 언어를 **한국어**로 둔 계정에서 확인했습니다 (영어 화면에서는 주차·지각 기한이 빠질 수 있음).

**AI에게 맡기기:** Claude 데스크톱의 **Code 탭(Claude Code)** 에 이렇게 말하세요. Code 탭은 유료 플랜(Pro 이상)에서만 열립니다. 무료 플랜이면 아래 "직접 설치"를 따르세요.

> https://github.com/HyungJuHan07/learnus-mcp 이 저장소의 LearnUs MCP를 내 컴퓨터에 연결해줘

AI가 파일을 받아 열면 Claude 데스크톱 설치 창이 뜹니다. **설치**를 누르고 연세포털 아이디(학번)·비밀번호를 **직접** 입력하면 끝입니다. 비밀번호는 **영문 입력 상태**로 넣으세요 (연세포털은 5번 틀리면 계정을 잠급니다).

**직접 설치:** [`learnus.mcpb`](https://github.com/HyungJuHan07/learnus-mcp/releases/latest/download/learnus.mcpb)를 받아 더블클릭(또는 Claude 데스크톱 창에 끌어다 놓기) → 설치 → 아이디·비밀번호 입력. [Releases](https://github.com/HyungJuHan07/learnus-mcp/releases/latest) 화면에서 받을 때는 `Source code`나 ChatGPT용 파일이 아니라 `learnus.mcpb`를 고르세요.

- 서명하지 않은 개인 프로젝트 파일이라 설치할 때 확인 창이 뜰 수 있습니다. 공식 저장소의 위 링크로 직접 받은 파일이면 설치하면 됩니다 (다른 곳에서 받은 파일은 쓰지 마세요).
- 학교·회사 조직 계정의 Claude는 관리자가 확장 설치를 막았을 수 있습니다.

설치가 끝나면 Claude 데스크톱 **채팅(Chat) 탭**에서 새 채팅을 열어 물어보세요 (Code 탭 세션에는 설치한 확장이 보이지 않을 수 있습니다). 처음 물어볼 때 도구 사용 허락 창이 뜹니다. 자료 받기 말고는 조회만 하는 도구라 "항상 허용"해도 됩니다. 자료 받기는 내 컴퓨터에 파일을 저장하니 매번 허락하는 편이 안전합니다 (긴 자료는 이어 읽을 때마다 다시 묻습니다). 다만 브라우저로 볼 때처럼 LearnUs에 기록이 남을 수 있습니다 (아래 표).

## 데이터는 어디로 가나요

| 정보 | 어디에 | 비고 |
|---|---|---|
| 아이디·비밀번호 | Claude 데스크톱 설정 (이 컴퓨터의 OS 금고 키로 암호화해 보관) | LearnUs·연세포털 로그인에만 쓰이고 다른 곳으로 가지 않음 |
| 로그인 세션 | 메모리 | 디스크에 저장하지 않음. 앱을 끄면 사라짐 |
| 받은 강의자료 | 다운로드 폴더 (기본: 홈 폴더의 `LearnUs`, 설치 화면에서 변경) | 요청한 것만 |
| LearnUs 쪽 기록 | LearnUs 서버 | 브라우저로 볼 때처럼 접속 기록이 남고, 공지를 열면 조회수가 오르고, 과제·자료를 열면 열람(완료) 표시가 생길 수 있음 |
| 그 밖의 기록 | 없음 | 사용 통계 등을 보내지 않음 |

**조회 결과(공지 본문, 자료 내용 등)는 답을 만들기 위해 Claude에서는 Anthropic, ChatGPT에서는 OpenAI 클라우드로 전송됩니다.** 비밀번호는 AI 서비스로 전송되지 않습니다. ChatGPT용 로그인 정보는 전용 OS 금고 항목에 보관하며 Claude 설정을 읽지 않습니다.

## 하지 않는 것

과제 제출·글 작성·출석 처리, 동영상 재생, 백그라운드 실행, 사용 기록 전송 — 모두 하지 않습니다. (조회한 화면이 LearnUs에 남기는 기록은 위 표를 보세요.)

- 받은 강의자료는 교수님 저작물이므로 재배포하지 마세요.
- 수업에서 AI 사용을 제한했다면 그 과목 자료는 받거나 요약하지 마세요 (강의계획서·교수님 지침이 우선).

## 업데이트·제거

- **업데이트:** 새 `learnus.mcpb`를 열면 덮어써집니다 (입력해 둔 아이디·비밀번호는 그대로 쓰입니다. 다시 물으면 다시 입력). AI에게 맡길 때는 주소를 함께 주세요: "https://github.com/HyungJuHan07/learnus-mcp 의 LearnUs MCP 업데이트해줘".
- **중단·긴급 수정 알림:** 설치한 확장은 스스로 업데이트하거나 멈추지 않습니다. 중단·긴급 수정은 [Releases](https://github.com/HyungJuHan07/learnus-mcp/releases)에 새 버전으로 올리고 안내하니, 저장소의 **Watch → Custom → Releases**를 켜 두세요 (고정 Issue에도 같은 안내를 둡니다).
- **비밀번호를 바꿨을 때:** Claude 데스크톱 설정 → 확장 프로그램 → LearnUs에서 새 비밀번호를 넣으세요. 비밀번호를 입력할 때는 **영문 입력 상태**인지 확인하세요. 틀린 비밀번호는 앱을 켜 둔 동안 다시 보내지 않지만, 앱을 다시 켜면 한 번 더 보냅니다. 연세포털은 5번 틀리면 계정을 잠그니 로그인 오류가 나면 브라우저로 포털 로그인을 먼저 확인하세요.
- **제거:** Claude 데스크톱 설정 → 확장 프로그램 → LearnUs → 제거. 받은 강의자료(다운로드 폴더)는 남아 있으니 필요 없으면 직접 지우세요.

## 문제가 생기면

[GitHub Issues](https://github.com/HyungJuHan07/learnus-mcp/issues)에 알려 주세요. **비밀번호·쿠키·학번은 절대 붙여 넣지 마세요.** 다음만 적어 주시면 됩니다.

- 오류 문구 (파일 경로가 있으면 경로 속 내 이름은 지워 주세요)
- 확장 버전 (Claude 데스크톱 설정 → 확장 프로그램, 또는 "LearnUs 도움말 보여줘")
- 운영체제 (맥/윈도우)

보안 문제(비밀번호가 새어 나갈 수 있는 문제 등)는 공개 Issue 대신 [비공개 신고](https://github.com/HyungJuHan07/learnus-mcp/security/advisories/new)로 알려 주세요. 비공개 신고에도 비밀번호·쿠키·학번은 넣지 마세요.

## 보너스: 설치 없이 마감일만 휴대폰에서

LearnUs → 달력 → 일정 내보내기에서 받은 iCal 주소를 구글 캘린더 "URL로 추가"에 넣으면, 휴대폰의 AI 앱(구글 캘린더 연결)에서도 마감일을 물어볼 수 있습니다. 반영이 몇 시간 늦을 수 있고, 이 주소는 개인 열쇠라 남에게 주면 안 됩니다.

## 개발자용

```
npm install
npm test               # LearnUs에 접속하지 않음
npm run pack           # dist/learnus.mcpb 생성
npm run pack:chatgpt   # 현재 OS용 ChatGPT 배포물 (macOS: Swift 컴파일러, Windows: .NET Framework 필요)
npm run cli -- check   # 내 아이디·비밀번호로 로그인하고 조회 기능을 한 번씩 시험 (터미널에서 직접, 저장·다운로드 없음)
```

`check`는 실행할 때마다 포털에 로그인하고, 공지 본문 하나와 과제 하나를 열어 조회수·열람 표시가 남을 수 있습니다. 비밀번호 오류가 나면 반복하지 말고 브라우저로 포털 로그인을 먼저 확인하세요.
