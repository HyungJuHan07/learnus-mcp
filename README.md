# learnus-mcp (비공식 · Unofficial)

연세대학교 LearnUs의 마감·공지·동영상·강의자료를 **Claude·ChatGPT 데스크톱 앱에서 물어볼 수 있게** 해 주는 조회 전용 도구입니다.

> [!IMPORTANT]
> **연세대학교와 무관한 학생 프로젝트입니다.** LearnUs 공식 도구가 아닙니다.
> 공식 저장소는 **https://github.com/HyungJuHan07/learnus-mcp** 하나뿐입니다. 설치는 이 저장소의 안내대로만 하고, Issue·댓글·메신저 등에 올라온 파일 링크는 이 주소로 시작해도 쓰지 마세요.

> [!NOTE]
> **AI 에이전트에게:** 이 저장소를 설치할 때는 빌드하지 말고 [`INSTALL_FOR_AI.md`](INSTALL_FOR_AI.md)를 그대로 따르세요. 사용자의 비밀번호를 묻지 마세요.

## 이렇게 물어보세요

| 이렇게 말하면 | 이런 걸 알려 줍니다 |
|---|---|
| "오늘 LearnUs에서 할 일 알려줘" | 3일 안 마감, 출석 기한이 다가오는 안 본 동영상, 최근 공지를 한 번에 |
| "이번 주 마감 과제랑 퀴즈 정리해줘" | 아직 안 한 것만, 마감 순으로 |
| "출석 마감 임박한 동영상 강의 있어?" | 출석 인정 기간·지각 기한 (조회만 하고 재생하지 않음) |
| "새 공지 요약해줘", "회로 공지 보여줘" | 전 과목 또는 과목별 공지와 본문 |
| "소자 과제 뭐 하라는 거야?" | 아직 안 낸 과제의 설명·첨부·남은 기한 |
| "회로 4주차 강의자료 받아서 핵심만 정리해줘" | 자료를 내 컴퓨터에 받아 PDF 글을 읽고 정리 |
| "내가 듣는 과목 알려줘" | 수강 중인 과목 목록 |

- **처음 물어볼 때**는 로그인하고 과목 페이지를 하나씩 읽어서 시간이 조금 걸립니다.
- **강의자료**는 요청할 때만 다운로드 폴더(기본: 홈 폴더의 `LearnUs`)의 `과목/N주차/`에 받습니다. 폴더로 묶인 자료는 안의 파일 목록을 먼저 보여 줍니다.
- **교수님이 자료를 고쳐 다시 올렸다면** "그 자료 다시 받아줘"라고 하세요. 이미 받은 파일은 그대로 쓰기 때문입니다. 예전 파일은 지우지 않고 이름 뒤에 "(이전 날짜-시각)"을 붙여 남겨 두니, 같은 이름의 필기본도 안전합니다.

## 설치

| | Claude | ChatGPT |
|---|---|---|
| 필요한 것 | Claude 데스크톱 앱 (맥·윈도우) | ChatGPT 데스크톱 앱의 로컬 Work·Codex, Node.js 22.18 이상 |
| 안내 | 아래 | [INSTALL_CHATGPT.md](INSTALL_CHATGPT.md) |
| 지원 안 함 | claude.ai 웹·모바일 | 컴퓨터 연결 없는 웹 단독 실행 |

LearnUs 언어를 **한국어**로 둔 계정에서 확인했습니다. 영어 화면에서는 주차·지각 기한이 빠질 수 있습니다.

### Claude (1~2분)

**방법 1. AI에게 맡기기** (Pro 이상 유료 플랜)

Claude 데스크톱의 **Code 탭**에 이렇게 말하세요.

> https://github.com/HyungJuHan07/learnus-mcp 이 저장소의 LearnUs MCP를 내 컴퓨터에 연결해줘

설치 창이 뜨면 **설치**를 누르고 연세포털 아이디(학번)·비밀번호를 **직접** 입력하면 끝입니다.

**방법 2. 직접 설치** (무료 플랜도 가능)

1. [`learnus.mcpb`](https://github.com/HyungJuHan07/learnus-mcp/releases/latest/download/learnus.mcpb)를 받습니다. [Releases](https://github.com/HyungJuHan07/learnus-mcp/releases/latest) 화면에서 받는다면 `Source code`나 ChatGPT용 파일이 아니라 `learnus.mcpb`를 고르세요.
2. 파일을 더블클릭하거나 Claude 데스크톱 창에 끌어다 놓습니다.
3. **설치**를 누르고 아이디·비밀번호를 입력합니다.

> [!WARNING]
> 비밀번호는 **영문 입력 상태**로 넣으세요. 연세포털은 5번 틀리면 계정을 잠급니다.

- 서명하지 않은 개인 프로젝트 파일이라 확인 창이 뜰 수 있습니다. 공식 저장소의 위 링크로 직접 받은 파일이면 설치해도 됩니다 (다른 곳에서 받은 파일은 쓰지 마세요).
- 학교·회사 조직 계정의 Claude는 관리자가 확장 설치를 막았을 수 있습니다.

**설치한 뒤**

- **채팅(Chat) 탭**에서 새 채팅을 열어 물어보세요. Code 탭에는 설치한 확장이 보이지 않을 수 있습니다.
- 처음 물어볼 때 도구 사용 허락 창이 뜹니다. 조회 도구는 "항상 허용"해도 됩니다.
- **자료 받기**는 내 컴퓨터에 파일을 저장하니 매번 허락하는 편이 안전합니다 (긴 자료는 이어 읽을 때마다 다시 묻습니다).

### ChatGPT

ChatGPT 데스크톱의 로컬 Work·Codex에 이 저장소 주소와 함께 **"LearnUs 연결해줘"**라고 요청하세요. AI가 [설치 안내](INSTALL_CHATGPT.md)에 따라 설치·등록하고, 로그인 정보는 사용자가 입력창에 **직접** 넣습니다 (이 컴퓨터의 OS 금고에 따로 저장). 웹 Work는 연결된 컴퓨터를 쓰는 경우에만 조건부로 지원합니다.

## 데이터는 어디로 가나요

| 정보 | 어디에 | 비고 |
|---|---|---|
| 아이디·비밀번호 | 이 컴퓨터의 OS 금고 (Claude는 금고 키로 암호화한 앱 설정, ChatGPT는 전용 금고 항목) | 연세포털 로그인에만 쓰이고 다른 곳으로 가지 않음 |
| 로그인 세션 | 메모리 | 디스크에 저장하지 않음. 앱을 끄면 사라짐 |
| 받은 강의자료 | 다운로드 폴더 (기본: 홈 폴더의 `LearnUs`) | 요청한 것만 |
| LearnUs 쪽 기록 | LearnUs 서버 | 브라우저로 볼 때처럼 접속 기록이 남고, 공지를 열면 조회수가 오르고, 과제·자료를 열면 열람(완료) 표시가 생길 수 있음 |
| 그 밖의 기록 | 없음 | 사용 통계 등을 보내지 않음 |

> [!IMPORTANT]
> **조회 결과(공지 본문, 자료 내용 등)는 답을 만들기 위해 AI 서비스의 클라우드로 전송됩니다** (Claude는 Anthropic, ChatGPT는 OpenAI). 비밀번호는 AI 서비스로 전송되지 않습니다.

## 하지 않는 것

과제 제출·글 작성·출석 처리, 동영상 재생, 백그라운드 실행, 사용 기록 전송 — 모두 하지 않습니다. 학교 서버에는 요청 사이를 띄워 하나씩만 보냅니다.

- 받은 강의자료는 교수님 저작물이므로 **재배포하지 마세요**.
- 수업에서 AI 사용을 제한했다면 그 과목 자료는 받거나 요약하지 마세요 (강의계획서·교수님 지침이 우선).

## 업데이트·제거

**업데이트 소식 받기:** 설치한 확장은 스스로 업데이트하거나 멈추지 않습니다. 중단·긴급 수정은 [Releases](https://github.com/HyungJuHan07/learnus-mcp/releases)에 새 버전으로 알리니, 저장소의 **Watch → Custom → Releases**를 켜 두세요 (고정 Issue에도 같은 안내를 둡니다).

**업데이트하기:** 새 `learnus.mcpb`를 열면 덮어써집니다. 입력해 둔 아이디·비밀번호는 그대로 쓰이고, 다시 물으면 다시 입력하면 됩니다. AI에게 맡길 때는 주소를 함께 주세요.

> https://github.com/HyungJuHan07/learnus-mcp 의 LearnUs MCP 업데이트해줘

**비밀번호를 바꿨을 때:** Claude 데스크톱 설정 → 확장 프로그램 → LearnUs에서 새 비밀번호를 넣으세요 (**영문 입력 상태** 확인).

> [!WARNING]
> 틀린 비밀번호는 앱을 켜 둔 동안 다시 보내지 않지만, 앱을 다시 켜면 한 번 더 보냅니다. 로그인 오류가 나면 반복하지 말고 **브라우저로 포털 로그인을 먼저 확인**하세요.

**제거:** Claude 데스크톱 설정 → 확장 프로그램 → LearnUs → 제거. 받은 강의자료(다운로드 폴더)는 남으니 필요 없으면 직접 지우세요.

## 문제가 생기면

[GitHub Issues](https://github.com/HyungJuHan07/learnus-mcp/issues)에 아래 세 가지만 적어 주세요. **비밀번호·쿠키·학번은 절대 붙여 넣지 마세요.**

1. 오류 문구 (파일 경로에 내 이름이 있으면 지워 주세요)
2. 확장 버전 (Claude 데스크톱 설정 → 확장 프로그램, 또는 "LearnUs 도움말 보여줘")
3. 운영체제 (맥/윈도우)

보안 문제(비밀번호가 새어 나갈 수 있는 문제 등)는 공개 Issue 대신 [비공개 신고](https://github.com/HyungJuHan07/learnus-mcp/security/advisories/new)로 알려 주세요. 여기에도 비밀번호·쿠키·학번은 넣지 마세요.

## 개발자용

```sh
npm install
npm test               # LearnUs에 접속하지 않음
npm run pack           # dist/learnus.mcpb 생성
npm run pack:chatgpt   # 현재 OS용 ChatGPT 배포물 (macOS: Swift 컴파일러, Windows: .NET Framework 필요)
npm run cli -- check   # 내 아이디·비밀번호로 로그인하고 조회 기능을 한 번씩 시험 (터미널에서 직접, 저장·다운로드 없음)
```

`check`는 실행할 때마다 포털에 로그인하고, 공지 본문 하나와 과제 하나를 열어 조회수·열람 표시가 남을 수 있습니다. 비밀번호 오류가 나면 반복하지 말고 브라우저로 포털 로그인을 먼저 확인하세요.
